COLORPOP — YOUR FIRST WEBSITE

FILES
- index.html : page structure
- style.css  : colors, layout, responsive design, animations
- script.js  : interactive buttons and theme switching

HOW TO RUN
1. Extract EXAMPLE.zip.
2. Open the extracted EXAMPLE folder in Visual Studio Code.
3. Open index.html.
4. For the easiest live preview, install the "Live Server" extension in VS Code.
5. Right-click index.html and choose "Open with Live Server".

You can also open index.html directly in your browser. Google Fonts need an internet connection;
the rest of the site works locally.
